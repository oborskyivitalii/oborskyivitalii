# Problem space model

State the boundary, affected parties, proposed mechanism and unresolved
conditions. Separate observed facts from inferred links. Compare at least two
plausible explanations, including an unchanged baseline when useful. Name a
specific observation that would reject each explanation. Return a bounded thesis
and outline with literal primary-source excerpts and evidence gaps.
