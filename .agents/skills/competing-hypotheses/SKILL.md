# Competing hypotheses

Adapted for editorial review from TJ Boudreaux's Scientific Method
(Hypothesis Differential), revision `7b8fece345dfaa11773be7152ccd194589cb5437`.
See [provenance](SOURCES.md) and [license](LICENSE).

1. State the claim, where it applies, and the actual observation separately.
2. Enumerate serious competing explanations and identify an observation
   that would rule each one out. If only one is plausible, assess it directly.
3. Start with an accessible primary observation that distinguishes the
   leading explanations. Quote the smallest decisive passage and say what
   it supports or excludes. Check the population, time and measurement.
4. Eliminate explanations that conflict with the observation. Prefer fewer
   assumptions only among survivors. If the original claim survives in a
   smaller scope, supply the exact narrower thesis and outline.
5. Give the disposition and reasoning. Keep the claim open if the evidence
   is inaccessible, nondiscriminating or requires work that has yet to run.
