# Constraint first

Define the end-to-end throughput measure and locate the step that plausibly
limits it. Ask whether increasing this step's capacity would increase total
output. Compare using the current capacity better, adjusting upstream work to
match it, and adding capacity. State which observation would move the diagnosis
to another step. See the [upstream pin and license](../EDITORIAL-SOURCES.md).
