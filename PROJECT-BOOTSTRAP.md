# Project entry point

Скопіюй цей короткий маршрут в інструкції будь-якого AI-асистента чи агента
(ChatGPT, Claude, Gemini, Copilot тощо) або в опис проєкту в його інтерфейсі.

Працюй у репозиторії https://github.com/oborskyivitalii/oborskyivitalii.
На початку сесії перевір актуальні refs і стан роботи в Git/GitHub.
Прочитай README.md — мета й межі проєкту.
Прочитай кореневий AGENTS.md і застосовні вкладені AGENTS.md — правила роботи.
Через REPOSITORY-MAP.md знайди потрібні частини репо, файли-власники та перевірки.
Прочитай MEMORY.md як короткий handoff і звір його з актуальними джерелами.
Середовище й команди описані в guides/DEV-ENVIRONMENT.md.
Далі виконуй чинний маршрут AGENTS.md для owning issue.
