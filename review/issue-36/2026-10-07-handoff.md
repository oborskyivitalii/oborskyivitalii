## Decisions

Compile the bounded canonical SVG during normal generation into numeric commands.
The browser rasterizes it once into one **1380 × 240** transparent Canvas cache,
**1,324,800 bytes** nominal RGBA, independent of viewport/DPR/theme/detail/visits.
Per visible paint it submits one drawImage command at the formula's sorted depth.
There is no runtime SVG fetch, XML parsing, text shaping, image decode or new RAF.
Diagnostics expose actual build/paint/failure counts and bounded room models.

This allowed prebuilt-vector implementation supersedes delayed Image-decode
fixtures: missing/malformed artwork fails generation atomically; cache creation
failure is contained once and preserves the rest of Canvas/HTML/navigation.
The static Writing fallback embeds canonical outlined markup with mutually
exclusive mobile/desktop framing. Standalone export embeds compiled runtime and
all routes; it does not need an external formula asset.

The new evidence job is opt-in via exact label `site-writing-paradigm-evidence`
on same-repository PR #38, reusing `site-writing-probe.yml`. Ordinary PR updates
keep Basic/Preview. The job packages exact baseline/head Color artifacts, runs
focused Linux browser evidence then serial paired measurements, and uploads raw
JSON/captures for 90 days even on failure. It does not publish or supply full
release acceptance. Current result links belong to the issue anchor.

## Performance and stability protocol

The original before-measurement guardrails remain unchanged: median paired
painted-callback p95 increase ≤max(1 ms, 10% baseline), idle busy increase ≤2
percentage points, cold Writing readiness increase ≤max(50 ms, 5% baseline).
Before any actual candidate measurement, independent review adds the explicit
coverage guard: actual candidate paint rate may not fall below 90% of its paired
baseline (one-paint rounding tolerance for short windows). Require actual formula
paint deltas during measured Writing windows; historical cache paintCount alone
cannot establish visibility. Do not alter limits after failures to manufacture a pass.

| Scope | Required evidence |
| --- | --- |
| Source/variant | Clean frozen baseline and candidate SHA/tree/public digest; normal producers; authored Color with ribbons/travel; same runner/browser/gzip fixture |
| Profiles | Desktop 1440×900 DPR1 CPU×1; mobile 390×844 DPR3 CPU×1 and synthetic CPU×4; theme Night |
| Pairing | Sequential A/B, B/A, A/B, fresh process/context per trial, disabled browser cache; all trials/raw frames/events retained |
| Motion | 4 s Writing idle, 4 s bidirectional scroll, filtered and empty/reflow windows; callbacks, p95/busy/gaps/actual paint coverage, quality/cadence and formula draw deltas |
| Flights | Cold Research→Writing→Talks, warm Talks→Writing→Research; preparation/readiness and final-room artwork absence |
| Asset | Exact raw/gzip route transfer delta and resource timing; formula-specific network requests and decode calls zero; fixed cache once |
| Stability | Once/profile 40 route changes after warm-up, forced-GC DOM/listener/model/cache observation; settled Off/reduced/hidden/print zero work, positive restore |
| Visual/browser | Linux Chromium/Firefox/WebKit Writing normal/no-JS/no-Canvas/reduced checks; Chromium 320/390/768/1440 Day/Night, CSS200% zoom, room journey/cache fault, offline copy |
