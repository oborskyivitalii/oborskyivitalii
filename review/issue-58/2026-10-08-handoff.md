soft 100 columns, strict HTML whitespace sensitivity, unchanged prose wrapping,

HTML/CSS changes reviewable. Restore and resolve any semantic mismatch explicitly.

JSON/YAML values and CSS rules using existing parsers/stdlib where sufficient.

do not normalize away a visible change. Execute assembled browser scripts as well
as comparing syntax. Check base math/world/projection/lifecycle/renderer factories
and Flight/Ribbons code/controls through maintained engine/effect/flight/ribbon tests.

composition, lifecycle/geometry samples, CSS paint and existing resource bounds.

Producer/runtime/snapshot/variant/lock identities must derive from new source;
never patch hashes manually. Bind final reports/smoke to one clean exact candidate,
tree and artifact. No speed improvement is implied by formatting.
