# P1 — Writing mount and native layout

5 October 2026. Owner #12, evidence #13. This is the focused layout increment
after R1. It is not accepted performance or a hosted release.

The opt-in `SiteEngineStages` diagnostic separates DOM/archive/scroll/native
layout, model construction/palette, projection/effects/sort/Canvas submission.
Normal budget runs set only the existing `SiteEngineProbe`; fine stage clocks
and events are off. Whole RAF and input-to-ready accounting remain unchanged.
Mount is still inside the same measured callback.

The first diagnostic found a computed scroll-style flush (9.6 ms) followed by
native range layout (30.5 ms) inside an 88.1 ms callback. A root-style transaction
alone did not remove the second cost and was discarded. Explicit `instant`
scroll behavior replaces the older computed-auto workaround: it ignores smooth
anchor CSS without temporarily mutating the root or restoring a dirty style.
This supersedes the old handoff's requirement to keep that specific workaround,
while preserving its requirement for immediate native restoration.

Mount and nested scene reads now use one native presentation scope. A cached
plane offset from that snapshot avoids a read after presentation resumes.
An active Canvas hides its SVG fallback with `display:none` as well as visibility;
removing `data-ready` on failure restores the original SVG automatically.
Adaptive decorative quality consumes render cost rather than archive mount cost.
No extra RAF, postponed mount, relaxed gate or artificial scroll height was added.
