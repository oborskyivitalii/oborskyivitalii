## Implemented

Navigation owns an end intent keyed by route and navigation serial. Native scene
measurement reconciles that intent **before** reading waypoints, including after
archive/footer reflow. Arrival clears the presentation transform and reconciles
again. The existing invalidation/scheduler handles normal Canvas paths; only a
missing Canvas engine installs a bounded ResizeObserver. Initial settling ends
after one second; the timeout bounds ownership, never drives restoration.

New deliberate wheel/key/touch/pointer input, interruption, print, blur and page
exit release the intent. Programmatic scroll is not mistaken for new input.
Back/Forward continues to use its separate saved position. No second RAF exists.

A second defect was reproduced after the first reflow repair: the accepted
wheel gesture's tail moved instant Writing 270px away from its bottom, and held
PageUp repeats moved it 1771px. The edge controller now supplies the accepted
input type. Navigation consumes only that wheel tail or held key's repeats,
until a fresh gesture/key release, interruption or loss of focus. One tiny
route-scoped input record persists until that gesture ends; it owns no observer,
render loop or polling timer. Touch already retains its original bounded target
listeners until end/cancel. Wheel freshness uses event creation timestamps so
main-thread delay cannot manufacture a fresh gesture from queued inertia.

## Evidence

The final source passes 48 ordinary/late-growth reverse cases: both base/Color
variants, both widths, all three adjacent route pairs, Motion On/Off, cold/warm
reuse. Thirty-six additional Color cases use actual wheel/key/CDP touch with
the accepted tail and content flight On/Off. Every endpoint gap is ≤2 CSS px.
Fresh-input takeover and a middle Back/Forward position pass in all four
contexts; reduced motion, intent expiry and short growing destinations pass.
The earlier intentional failures remain in the evidence and are not relabeled.

`tools/quality/navigation.cjs` adds the reverse-end/reflow/takeover/history fixture
to the existing hosted suite and its required aggregate checks. The default basic
suite remains ten tests. Diagnostic scripts in this directory are not defaults.

The original top-landing report has more than one plausible mechanism; the
reproduced same-gesture transfer and reflow gap are repaired, not asserted to
explain every unobserved case. Current raw source hashes and rows are in
`evidence/reverse-final.json` and `evidence/input-tail-before.json`.
