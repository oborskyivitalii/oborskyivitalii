## Findings and correction evidence

**F01 — blocking, CR01:** local `.git/info/grafts` could claim that a genuinely
parentless H descended from B. Requirements constructed this exact case; the old
prototype returned `structurally-supported`. Three other initial role accepts
did not override this independently reproduced contract defect.

The central Git helper now sends `GIT_GRAFT_FILE` to the platform null device for
every invocation, alongside `--no-replace-objects` and `GIT_NO_LAZY_FETCH`.
The regression first proves ambient Git accepts the invented parent, then proves
the prototype blocks it. All four roles actually rechecked the correction;
Requirements and Exploratory also reran separate original CLI counterexamples.
F01 is resolved, without broadening structural authority.

The first focused run had one fixture failure: duplicate package entries shared
a JavaScript reference, so mutating the fixture changed both entries. The fixture
now clones the duplicate independently; no production guard was weakened.
The RI coupling test retains exact layer equality and adds the one new declared
layer. Canonical formatting is applied without unrelated Python reformatting.
Earlier failed checks remain failed historical observations, not current passes.
