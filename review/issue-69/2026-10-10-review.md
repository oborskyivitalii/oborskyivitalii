| Approach | Assessment |

| One-shot observer plus CSS entry | Recommended: bounded event work, native DOM text, stable shells and existing lifecycle hooks. Still requires browser/compositing/overflow measurement. |
| Per-scroll JS transforms | Reject for first implementation: hot-loop layout/style risk and unnecessary continuous coupling to scroll. |
