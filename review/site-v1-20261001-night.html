01 / Research

Two directions, connected.

01 How we deliver software

The Subprime
Code Crisis

What happens across review, testing, security and maintenance when generating code gets easier? This project studies AI-assisted delivery as a complete system, with an inspectable evidence library and adaptable operating protocols.

  • Verification capacity
  • System throughput
  • Long-term ownership

02 What we build

Uncertainty
Architecture

How do we design and operate software whose behavior depends on probabilistic model judgment? This project develops an engineering vocabulary and patterns for boundaries, evaluation, authority, runtime control and correction.

  • Model judgment
  • Control architecture
  • Release & runtime evidence
