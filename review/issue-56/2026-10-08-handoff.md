descriptors. Color no longer patches `variants.attach` or reverse-engineers effect
CSS/control scripts from HTML with regexes. Offline adapters retain the existing
markers, wrappers and variant fingerprints.

canonical paths. Three retained historical diagnostics import maintained helpers;
their findings and historical reports are not rewritten. Source profiles include
permanent descriptor tests and the complete new input closure. Task-specific
issue56 parity snapshots run only through the owning acceptance policy.

Source moves and the new build adapter legitimately change producer identities.
The ordinary builder regenerates route/runtime snapshot paths, output lock,
offline previews and gallery. No output identity is patched by hand. Catalog and
RI/CI mapping must match that exact regenerated source.

## Free tooling decision

The repository already pins ESLint with SonarJS, Stylelint, Ruff, Semgrep CE,
Bandit, detect-secrets and dependency audits. R1 extends coverage rather than
introducing another server or scanner: ESLint checks canonical effect modules,
Stylelint checks every authored `site/**/*.css` plus delivered `docs/styles.css`,
and source checks fail instead of silently dropping missing inputs.
